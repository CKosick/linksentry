100% On-Device & Zero-Telemetry

LinkSentry Privacy Policy

Last updated: October 13, 2026

1. The Short & Plain Summary

LinkSentry collects no personal data and stores nothing off your device. There are no accounts, no trackers, no analytics scripts, no advertising SDKs, and no telemetry pings.

The only outbound network requests LinkSentry ever makes are the HTTP status checks (HEAD/GET) to the links present on the web page you explicitly choose to scan when you click the extension.

2. What Data Is Processed

  • Current Page Links: When you trigger a scan, LinkSentry reads the link targets (URLs) on your current browser tab in order to test their HTTP status. This data remains in memory on your machine and in your browser's local extension storage.
  • Extension Settings: User preferences (such as custom outline highlight colors) are saved locally using Chrome's on-device storage API (chrome.storage.local).

3. Network Communications

LinkSentry communicates exclusively with the URLs being tested on the page you choose to inspect. It does this by issuing lightweight HTTP HEAD requests (with a fallback GET request if the host server rejects HEAD methods).

LinkSentry does not communicate with any central server, cloud service, analytics collector, or remote endpoint.

4. Data Retention

All scan results exist only in your browser session and local extension storage. Clearing your browser data, resetting results in the popup, or uninstalling the extension immediately removes all data.
